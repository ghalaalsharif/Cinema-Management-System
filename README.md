# Cinema Management System 🎬

A robust Java-based console application designed to manage cinema operations, including movie catalogs, customer registrations, and ticket booking processes. Developed as an academic project applying core Object-Oriented Programming (OOP) principles.

---

## 🚀 Features
* Movie Management: Support for abstract classes and inheritance (e.g., `ActionMovie`) to handle diverse movie genres and details.
* Ticket Booking & Cancellation: Implements the Bookable interface to handle ticketing operations seamlessly.
* Customer Management: Tracks customer details and their booked movies using dynamic collections (`ArrayList`, `TreeSet`).
* Exception Handling: Custom exception (`MovieNotFoundException`) to gracefully manage missing or unavailable movies.
* Object Cloning: Demonstrates cloning capabilities for ticket objects.

---

## 🛠️ Tech Stack & Concepts
* Language: Java
* Key Concepts: Object-Oriented Programming (OOP), Inheritance, Polymorphism, Interfaces, Exception Handling, Collections Framework.
